# ソシャゲ運営シミュ（シンプル版）

3年間（36ヶ月）資金を枯らさず運営を続けることが目的のソーシャゲーム運営シミュレーション。

## ゲーム概要

- **プレイ時間**: 15〜30分
- **ジャンル**: リスク管理・経営判断ゲーム
- **勝利条件**: 36ヶ月生存
- **敗北条件**: 資金0

## 基本ループ（月次）

1. 月開始
2. 行動（資金が続く限り何度でも）
3. 炎上判定
4. 月末収益計算
5. 次月へ

## ステータス

### 成長パラメータ

- **キャラ**: ガチャ実装で上昇
- **技術力**: コンテンツ実装で上昇
- **知名度**: 広告で上昇

### 状態パラメータ

- **ユーザ評価**: ★1〜5
- **ユーザ数**: 月末収益に影響
- **セルラン**: 演出用（ランキング表示）
- **運転資金**: 初期2000万円

## 行動システム

### 月内は何度でも行動可能

ただし行動するたびコストが指数増加する。

### 行動コスト式

```
cost = 100万円 × (1.4 ^ 行動回数)
```

例:
- 1回目: 100万円
- 2回目: 140万円
- 3回目: 196万円
- 4回目: 274万円

## 通常行動

### 1. ガチャ実装

- キャラ上昇
- 収益アイテム獲得（1ヶ月）
- 炎上率: 大

### 2. コンテンツ実装

- 技術力上昇
- 収益バフアイテム獲得（1ヶ月）
- 炎上率: 中

### 3. 広告

- 知名度上昇
- ユーザ増加バフ獲得（1ヶ月）
- 炎上率: 小

## アイテム

すべて1ヶ月寿命（月末で消滅）。

- **ガチャアイテム**: 収益+10%
- **コンテンツアイテム**: 収益+5%
- **広告アイテム**: ユーザ+10%

## 炎上システム

### 炎上確率

```
炎上率 = 5% + (当月行動数 × 4%)
```

例:
- 3行動 → 17%
- 6行動 → 29%
- 10行動 → 45%

### 炎上発生時

- 資金 -30%
- 評価 -1
- ユーザ -15%

## ユーザ変動

### 新規ユーザ

```
新規ユーザ = 知名度 × 100
```

### 離脱率

```
離脱率 = (6 - 評価) × 3%
```

## 月末収益

```
収益 = ユーザ数 × 評価補正 × バフ
```

### 評価補正

- ★1 = 0.5
- ★2 = 0.8
- ★3 = 1.0
- ★4 = 1.3
- ★5 = 1.6

## ゲーム性コンセプト

高収益を狙うほど炎上リスクが上昇する。**攻めるか、安全に行くかの判断が主なゲーム性**。

コンテンツ・広告・ガチャの投資バランスと資金管理が重要となる。

## 難易度設計目標

- 勝率: 30〜40%
- 平均寿命: 20ヶ月
- 最大: 36ヶ月

## 新機能（バランス調整用）

### ゲーム設定

タイトル画面から「ゲーム設定」を選択すると、以下のパラメータを調整できます：

- **基本設定**: 最大月数、初期資金、基本行動コスト、コスト倍率
- **炎上システム**: 基礎炎上率、行動毎増加率、資金減少率、ユーザ減少率
- **アイテム効果**: ガチャ収益率、コンテンツ収益率、広告ユーザ率
- **ユーザ変動**: 知名度あたり新規、初期ユーザ数、離脱率基礎値、離脱率倍率
- **評価補正**: ★1〜5の各倍率

設定は自動保存され、Rキーでデフォルトに戻せます。

### オートプレイ

タイトル画面から「オートプレイ」を選択すると、AIによる自動プレイが実行されます：

- **10回**: テスト用（数秒）
- **10,000回**: バランス確認用（数分）
- **1,000,000回**: 詳細分析用（数十分）

実行完了後、**結果画面**が自動表示されます：
- 実行回数
- 生存率（%）
- 平均/最長/最短生存月数
- 平均最終資金・ユーザ数
- 平均炎上回数
- 保存ファイル名と保存先

実行結果は以下のファイルとして保存されます：
- `autoplay_[日時].csv`: ゲームの詳細データ
  - 10回/10,000回: 全データ保存
  - 100万回: 最初の1,000件のみ保存（メモリ効率化）
- `autoplay_stats_[日時].txt`: 統計情報（生存率、平均生存月数など）
  - 全実行回数の完全な統計

保存先: `%APPDATA%\LOVE\helloworld\` (Windows)

```bash
love .
```

## ビルド・配布

```bash

7z a -tzip game.love main.lua fonts/

# 2. スタンドアロンexe作成
cat /path/to/love.exe game.love > SosyageSimSimple.exe

# 3. 必要なDLL（love.dll, lua51.dll, SDL2.dllなど）を同じフォルダにコピー
```
