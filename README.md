# ソシャゲ運営シミュレーション v5.8

ソーシャルゲームの開発・運営を体験する、2フェーズ制の経営シミュレーションゲーム。

## ゲーム概要

プレイヤーはソシャゲの開発・運営チームとして、限られたリソースを使って行動を選択し、48ヶ月（4年）の完走を目指す。開発期12ヶ月でゲームを作り上げ、運営期36ヶ月でサービスを維持する。資金が尽きるとサービス終了（ゲームオーバー）。

## ゲーム期間

- **開発期**: 12ヶ月（1〜12ヶ月目）
- **リリース**: 12ヶ月目終了時
- **運営期**: 36ヶ月（13〜48ヶ月目）
- **目標**: 48ヶ月完走

## リソース

ゲームは3つのリソースで進行する。すべてのリソースは月初に全回復する。

| リソース | 説明 |
|---|---|
| **知名度（N）** | 広報・マーケティングに必要。行動コストとして消費 |
| **コンテンツ（C）** | ゲーム内容の充実に必要。行動コストとして消費 |
| **技術力（T）** | システム開発・保守に必要。行動コストとして消費 |

- 初期値: 各10
- 月初に最大値まで全回復
- 最大値は行動で成長させる（成長上限なし）

## その他のパラメータ

| パラメータ | 説明 |
|---|---|
| **資金** | 運営資金（万円単位）。開発期は-2000万円の借金からスタート |
| **流行指数** | 内部パラメータ。運営期は画面に表示 |
| **ストア評価** | ★1〜★5で表示。運営期のみ |
| **セルラン** | 1位〜50位+のランキング。運営期のみ（v5.4追加） |
| **状況コメント** | 「SNSで話題」「堅調」などの表示。運営期のみ |

## 目標達成システム（v5.4追加）

- **運営1周年で借金完済**: 24ヶ月目（運営12ヶ月）で資金 >= 0
- **運営3周年でセルラン1位**: 48ヶ月目（運営36ヶ月）でセルラン = 1位

## 月の進行

### 1. 月初
- N/C/Tが最大値まで全回復
- 当月のイベント4件が提示される
- 未来のイベント3件が予告される（来月、2ヶ月後、3ヶ月後）

### 2. 行動選択（月4回）
毎月4回、以下から選択して実行：
- **イベント対応**: 当月発生したイベントに対応（プラス/マイナス混在）
- **通常行動**: リソース成長、収益アイテム獲得など
- **アイテム使用**: 行動消費なし、何回でも使用可能

### 3. 月末
- 未対応のマイナスイベントにペナルティ発生
- 恒常収益加算（運営期のみ、v5.6）
- 維持費支払い（運営期のみ、-200万円）
- 流行指数の減衰（運営期のみ、設定値）
- ストア評価・セルラン更新（運営期のみ）
- 目標達成判定（v5.4）

## イベントシステム

### イベントの種類
- **プラスイベント**: 対応すると成長やボーナス
- **マイナスイベント**: 対応しないと資金減少などのペナルティ

### イベント対応
- 各イベントにN/C/Tのコストが設定されている
- リソースを消費してイベントに対応できる
- 対応すると成長や効果を得られる
- 未対応のマイナスイベントは月末にペナルティ

## 通常行動

### 開発期（1〜12ヶ月）
- 広報活動: N消費、知名度上限+2
- コンテンツ制作: C消費、コンテンツ上限+2
- 技術開発: T消費、技術力上限+2
- **コンテンツ実装**: C/T消費、恒常/限定コンテンツ獲得
- **ガチャ実装**: N/C/T消費、恒常/限定ガチャ獲得
- 何もしない: コスト0

**注意**: 開発期は恒常アイテムのみ使用可能。限定アイテムは運営期まで保持。

### 運営期（13〜48ヶ月）
- 広報活動: N消費、知名度上限+2、流行+10
- コンテンツ追加: C消費、コンテンツ上限+2、流行+6
- 技術改善: T消費、技術力上限+2
- **コンテンツ実装**: C/T消費、恒常/限定コンテンツ獲得（v5.6）
- **ガチャ実装**: N/C/T消費、恒常/限定ガチャ獲得（v5.6）
- 何もしない: コスト0

## 収益システム（v5.6で完全再設計）

### 4種類の収益アイテム
1. **恒常コンテンツ**: 30-60万円/月（恒常収益）、流行+3〜8
2. **限定コンテンツ**: 300-600万円（一時）、流行+15〜30
3. **恒常ガチャ**: 40-80万円/月±30%（恒常収益・変動）、流行+5〜12
4. **限定ガチャ**: 500-1000万円±40%（一時・大変動）、流行-20〜-10

### 収益の仕組み
- **恒常収益**: 恒常コンテンツ・恒常ガチャが毎月末に自動収益
- **限定収益**: 限定コンテンツ・限定ガチャは使用時に即時収益
- **維持費**: 運営期200万円/月（開発期は0円）

## リリース（12ヶ月目終了時）

開発期の成果に基づいて流行指数が決定される：
- **基本流行** = 知名度上限 + コンテンツ上限 + 運（-20〜+20）
- **恒常アイテム補正** = (恒常コンテンツ数 + 恒常ガチャ数) × 3
- **最終流行** = 基本流行 + 恒常アイテム補正
- 初期資金として5000万円を獲得
- 運営期に移行

**戦略**: 開発期に恒常アイテムを多く実装すると有利！

## 勝利条件

- **48ヶ月完走**: 4年間サービスを継続
- **ゲームオーバー**: 運営期に資金が0未満になる

## UIの特徴（v5.7大幅改善）

### 2カラムレイアウト
- **左カラム**: イベント対応、通常行動の選択肢
- **右カラム**: 未来イベント予告、アイテム一覧

### カーソル表示
- 選択中の項目に「→ 」カーソルを表示
- 黄色でハイライト

### 選択位置記憶
- 左カラム・右カラムそれぞれの選択位置を記憶
- カラム移動時に前回の位置に復帰
- 同じ行動を繰り返す際に便利

### アイテム表示
- 右カラムに配置（最大18個表示）
- スクロール対応
- 2行表示（名前＋説明）

## オートプレイモード（v5.5追加）

- タイトル画面から「2: オートプレイモード」を選択
- 1～10000回の自動プレイが可能
- 統計集計・CSV出力機能付き
- ゲームバランス調整やデータ分析に使用

## ゲーム設定（v5.6追加）

- タイトル画面から「3: ゲーム設定」を選択
- 流行減衰率をカスタマイズ可能（デフォルト-2/月）
- 手動プレイ・オートプレイ共通の設定

## 実行方法

Love2Dがインストールされている環境で：

```bash
love .
```

## ビルド・配布

Love2D がインストールされている環境で、プロジェクトルートから以下の手順で配布用exeを作成できる。

```bash
# 1. ゲームファイルを.loveアーカイブにまとめる（zip形式）
7z a -tzip game.love main.lua fonts/ imgs/

# 2. love.exeとゲームデータを結合してスタンドアロンexeを作成
cat /path/to/love.exe game.love > SosyageRoguelike.exe

# 3. 必要なDLLを同じフォルダにコピー
#    love.dll, lua51.dll, SDL2.dll, OpenAL32.dll, mpg123.dll, msvcp120.dll, msvcr120.dll

# 4. まとめてzipで配布
```
