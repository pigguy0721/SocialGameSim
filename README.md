# ソシャゲ運営シミュレーション v5

ソーシャルゲームの開発・運営を体験する、2フェーズ制の経営シミュレーションゲーム。

## ゲーム概要

プレイヤーはソシャゲの開発・運営チームとして、限られたリソースを使って行動を選択し、60ヶ月（5年）の完走を目指す。開発期24ヶ月でゲームを作り上げ、運営期36ヶ月でサービスを維持する。資金が尽きるとサービス終了（ゲームオーバー）。

## ゲーム期間

- **開発期**: 24ヶ月（1〜24ヶ月目）
- **リリース**: 24ヶ月目終了時
- **運営期**: 36ヶ月（25〜60ヶ月目）
- **目標**: 60ヶ月完走

## リソース

ゲームは3つのリソースで進行する。すべてのリソースは月初に全回復する。

| リソース | 説明 |
|---|---|
| **知名度（N）** | 広報・マーケティングに必要。行動コストとして消費 |
| **コンテンツ（C）** | ゲーム内容の充実に必要。行動コストとして消費 |
| **技術力（T）** | システム開発・保守に必要。行動コストとして消費 |

- 初期値: 各10
- 月初に最大値まで全回復
- 最大値は行動で成長させる（成長上限なし）

## その他のパラメータ

| パラメータ | 説明 |
|---|---|
| **資金** | 運営資金（万円単位）。ゼロでゲームオーバー |
| **流行指数** | 内部パラメータ（非表示）。収益に影響 |
| **ストア評価** | ★1〜★5で表示。運営期のみ |
| **状況コメント** | 「SNSで話題」「堅調」などの表示。運営期のみ |

## 月の進行

### 1. 月初
- N/C/Tが最大値まで全回復
- 当月のイベント4件が提示される
- 未来のイベント3件が予告される（来月、2ヶ月後、3ヶ月後）

### 2. 行動選択（月4回）
毎月4回、以下から選択して実行：
- **イベント対応**: 当月発生したイベントに対応（プラス/マイナス混在）
- **通常行動**: リソース成長、安定的な行動

### 3. 月末
- 未対応のマイナスイベントにペナルティ発生
- 収益計算（運営期のみ）
- 維持費支払い（運営期のみ）
- 流行指数の減衰（運営期のみ）
- ストア評価更新（運営期のみ）

## イベントシステム

### イベントの種類
- **プラスイベント**: 対応すると成長やボーナス
- **マイナスイベント**: 対応しないと資金減少などのペナルティ

### イベント対応
- 各イベントにN/C/Tのコストが設定されている
- リソースを消費してイベントに対応できる
- 対応すると成長や効果を得られる
- 未対応のマイナスイベントは月末にペナルティ

## 通常行動

### 開発期（1〜24ヶ月）
- 広報活動: N消費、知名度上限+1
- コンテンツ制作: C消費、コンテンツ上限+1
- 技術開発: T消費、技術力上限+1

### 運営期（25〜60ヶ月）
- 広報活動: N消費、知名度上限+1、流行+5
- コンテンツ追加: C消費、コンテンツ上限+1、流行+3
- 技術改善: T消費、技術力上限+1

## リリース（24ヶ月目終了時）

開発期の成果に基づいて流行指数が決定される：
- 流行指数 = 知名度上限 + コンテンツ上限 + 運（-20〜+20）
- 初期資金として5000万円を獲得
- 運営期に移行

## 運営期の収益

月末に以下の計算が行われる：
- **収益**: (知名度上限 + コンテンツ上限) × 10 + 流行指数 × 5
- **維持費**: 200万円（固定）
- **流行減衰**: 毎月-2ずつ減少

## 勝利条件

- **60ヶ月完走**: 5年間サービスを継続
- **ゲームオーバー**: 運営期に資金が0未満になる

## 実行方法

Love2Dがインストールされている環境で：

```bash
love .
```

## ビルド・配布

Love2D がインストールされている環境で、プロジェクトルートから以下の手順で配布用exeを作成できる。

```bash
# 1. ゲームファイルを.loveアーカイブにまとめる（zip形式）
7z a -tzip game.love main.lua fonts/ imgs/

# 2. love.exeとゲームデータを結合してスタンドアロンexeを作成
cat /path/to/love.exe game.love > SosyageRoguelike.exe

# 3. 必要なDLLを同じフォルダにコピー
#    love.dll, lua51.dll, SDL2.dll, OpenAL32.dll, mpg123.dll, msvcp120.dll, msvcr120.dll

# 4. まとめてzipで配布
```
