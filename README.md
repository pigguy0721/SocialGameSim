# ソシャゲ運営ローグライク

ソーシャルゲームの運営者となり、サービス終了を回避し続けるカード選択型ローグライクゲーム。

## ゲーム概要

プレイヤーはソシャゲの運営チームとして、毎ターン（毎月）提示される3枚の行動カードから1つを選び、ゲームの存続を目指す。ユーザー数またはの資金がゼロになるとサービス終了（ゲームオーバー）。

## ステータス

| パラメータ | 説明 |
|---|---|
| ユーザー数 | ゲームの利用者数。ゼロでゲームオーバー |
| 資金 | 運営資金（万円単位）。ゼロでゲームオーバー |
| 体力 | 行動に必要なリソース。カード使用で消費、休養で回復 |
| コンテンツ力 | ゲーム内容の充実度（最大100） |
| 技術力 | サーバー・バグ対応力（最大100） |
| 話題性 | 注目度。新規ユーザー流入に影響（最大100、毎ターン自然減衰） |
| 課金圧 | 課金の強さ。売上に貢献するがユーザー離脱率も上昇（最大100） |

## ゲームシステム

### ターン進行（1ターン = 1ヶ月、4月スタート）

1. **収支計算**: 売上（ユーザー数 × 課金圧）と維持費が発生
2. **ユーザー変動**: 話題性に応じた新規流入、課金圧・コンテンツ力に応じた離脱
3. **話題性減衰**: 毎ターン自然に低下（経過年数で加速）
4. **カード選択**: 3枚のカードから1つ選んで実行、または休養

### カードの種類

- **通常カード**（7種）: 新キャラガチャ追加、イベント開催、バグ修正、サーバー増強、SNS広報、コラボ企画、課金アイテム追加
- **レアカード**（4種）: 大型アップデート、TV紹介される、神絵師が参加、無料石配布
- **災害カード**（4種）: 大規模バグ発生、炎上、競合タイトル登場、サーバーダウン（強制発動）

### 難易度の上昇

- 災害カード出現率がターン経過で上昇（15% → 最大45%）
- 維持費がターン経過で増加
- ユーザー離脱率がターン経過で加速
- カード成功率がターン経過で低下

### 評価ランク

| 生存期間 | ランク |
|---|---|
| 60ターン以上（5年） | 伝説の運営 |
| 36ターン以上（3年） | 安定運営 |
| 24ターン以上（2年） | まあまあ |
| 12ターン以上（1年） | 短命 |
| 12ターン未満 | 即サ終 |

## 操作方法

| キー | 動作 |
|---|---|
| ← → | カード選択 |
| ↓ | 休養を選択 |
| Enter / Space | 決定 |
| Esc | タイトルに戻る |
| F11 | ボーダーレスフルスクリーン切り替え |

## 技術情報

- **フレームワーク**: LÖVE (Love2D)
- **言語**: Lua
- **解像度**: 800×600（レターボックス付きスケーリング対応）
- **フォント**: Noto Sans JP

## ビルド・配布

Love2D がインストールされている環境で、プロジェクトルートから以下の手順で配布用exeを作成できる。

```bash
# 1. ゲームファイルを.loveアーカイブにまとめる（zip形式）
7z a -tzip game.love main.lua fonts/ imgs/

# 2. love.exeとゲームデータを結合してスタンドアロンexeを作成
cat /path/to/love.exe game.love > SosyageRoguelike.exe

# 3. 必要なDLLを同じフォルダにコピー
#    love.dll, lua51.dll, SDL2.dll, OpenAL32.dll, mpg123.dll, msvcp120.dll, msvcr120.dll

# 4. まとめてzipで配布
```
