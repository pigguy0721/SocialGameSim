# ソシャゲあるある → ゲーム要素マッピング

## コンセプト

プレイヤーが「ソシャゲ運営」をする際のアクションやイベントを、
**ソシャゲをプレイする側の体験**のメタファーでデザインする。
運営ゲームなのにプレイ体験がソシャゲそのもの、というメタ構造。

## ゲーム要素へのマッピング

### A. スタッフ雇用 → キャラガチャ

運営に必要なスタッフを「ガチャ」で引く。

```
【スタッフガチャ】
  コスト: 資金○○万
  排出: ★1（普通）〜 ★3（超有能）のスタッフ

  ★1 新人プログラマー   → 技術力 毎ターン+1
  ★1 アルバイトデザイナー → コンテンツ力 毎ターン+1
  ★2 ベテランエンジニア  → 技術力 毎ターン+2、バグ発生率↓
  ★2 人気イラストレーター → コンテンツ力 毎ターン+2、話題性 毎ターン+1
  ★3 カリスマPD        → 全ステータス 毎ターン+1、マンネリ↓
  ★3 伝説のシナリオライター → コンテンツ力 毎ターン+3、ファン熱量↑

  天井: 10連で★2以上確定
  スタッフ枠に上限あり（最大5人？）
  スタッフにも「退職」イベントがある
```

#### ガチャあるあるの反映

| ソシャゲあるある | 運営ゲームでの体験 |
|---|---|
| すり抜け | 欲しい職種じゃないスタッフが来る |
| 人権キャラ | ★3スタッフがいると劇的に楽になる |
| 限定ガチャ | 期間限定で「元大手P」など特別枠 |
| 爆死 | 大金使って★1ばかり |
| リセマラ | 開発期冒頭のスタッフガチャ（ゲーム全体のリセマラに相当） |
