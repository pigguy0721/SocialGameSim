# 数字爆発ローグライト 再構築指示書

## 🎯 ゲームコンセプト

経営テーマを持つ「数字インフレビルドゲーム」。
目的は生存ではなく、**短期間でどれだけ売上を爆発させられるか**。

安定やバランスよりも、壊れたビルドと指数成長の快感を最優先とする。

---

# 🧠 ゲームの核設計

## ❌ 削除する要素

- 炎上システム
- ランダム収益ブレ
- 生存率設計
- 自動バランス調整
- 経営安定重視思想

---

# 🎮 新ゲーム構造

## ターン制

- 全12ターン
- 各ターンでビルドを構築
- 最終売上がスコア

破産は無し。
スコアアタック型。

---

# 🎴 キャラ設計

キャラは4タイプ。

## 1. マーケ
- プレイヤー数 + 固定値

## 2. コンテンツ
- プレイヤー数 × 倍率

## 3. ガチャ
- ARPPU + 固定値

## 4. バフ
- 最終売上 × 倍率

---

# 🔥 効果処理順（重要）

1. 固定加算（プレイヤー数・ARPPU）
2. 個別倍率（プレイヤー数倍率など）
3. 最終倍率（バフ・レリック）

指数的成長を必ず発生させる。

---

# 💣 シナジー設計

## 同タイプボーナス

- 3枚揃う → 効果 ×2
- 5枚揃う → 効果 ×4

偏重ビルドが最強になる設計。

# 🚀 成長設計思想

線形成長は禁止。
指数成長を前提とする。

壊れビルドが出たとき、
明確に別次元の売上に到達する設計にする。
