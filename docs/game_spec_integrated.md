# ソシャゲ運営シミュレーション - 統合版仕様書

## ゲーム概要
- **ジャンル**: ソシャゲ運営シミュレーション
- **期間**: 全5年間（60ヶ月）
- **プレイ単位**: 1ヶ月 = 1ターン

---

## ゲーム構成

### 開発フェーズ（1〜2年目・24ヶ月）
- ゲーム開発期間
- 初期借金: **2000万円**
- リリースに向けた準備
- 収益なし、開発コストのみ

### 運営フェーズ（3〜5年目・36ヶ月）
#### 運営1年目（全体3年目・12ヶ月）
- **目標**: 借金完済（2000万円）
- **失敗時**: ゲームオーバー

#### 運営2年目（全体4年目・12ヶ月）
- 安定運営・成長期
- セルラン上位を目指す

#### 運営3年目（全体5年目・12ヶ月）
- **最終目標**: セルラン1位達成
- 最終評価による勝利条件判定

---

## 基本パラメータ

### リソース（N/C/T）
- **N（知名度）**: マーケティング・宣伝力
- **C（コンテンツ）**: ゲーム内容・品質
- **T（技術力）**: システム・開発力

### リソースの性質
- 毎月初に**最大値まで全回復**
- 行動時に**コストとして消費**
- 最大値は成長によって増加

---

## 月の進行フロー

### ① 月初
- N / C / T が最大値まで回復
- **イベントが4件発生**
  - プラスイベント／マイナスイベントが混在
  - パラメータ値に応じて内容・発生率が変化

### ② 行動フェーズ
- **行動回数**: 月4回
- **行動の種類**:
  - イベント対応（イベント1件を処理）
  - 通常行動（安定した効果）
- どちらも同じ行動枠を消費
- 行動時に N / C / T をコストとして支払う

### ③ 月末
- 未対応イベントの影響を処理
- 収益・支出の算出（運営フェーズのみ）
- 各種評価指標の更新

---

## イベントシステム

### イベントの種類
- **チャンスイベント（プラス）**: 対応すると収益・評価UP
- **リスクイベント（マイナス）**: 放置すると収益・評価DOWN

### イベント対応
- **対応する**: 行動枠1 + パラメータコスト消費
- **見送る**:
  - チャンスイベント → 影響なし
  - リスクイベント → 収益減少

### イベント発生ロジック
- N / C / T 系イベントが偏りすぎないよう調整
- パラメータ値に応じて発生率・内容が変化

---

## 通常行動

### 特徴
- ランダム性なし
- 効果が安定
- **成長が発生する**（最大値+1、月上限あり）

### 行動例（開発フェーズ）
- プロトタイプ制作
- チーム拡充
- マーケット調査

### 行動例（運営フェーズ）
- 大型アップデート
- コラボ企画
- インフラ強化

---

## 評価指標

### 運営フェーズでの評価
1. **セルラン順位**: 1位〜圏外
2. **プレイヤー数**: アクティブユーザー数
3. **売上**: 月次売上高
4. **ストア評価**: ★1〜★5

### 最終勝利条件
- 運営3年目（5年目）終了時点で:
  - セルラン1位達成
  - または総合スコアで高評価

---

## 収支システム（運営フェーズ）

### 収入
- ユーザー課金（プレイヤー数 × 課金率 × 単価）
- パラメータに応じて変動

### 支出
- 開発コスト（アップデート規模により変動）
- 運営コスト（固定費）
- 借金の利息

### 借金返済
- 運営1年目で2000万円完済が必須
- 未達成でゲームオーバー

---

## 成長システム

### 成長の発生条件
- イベント対応時
- 通常行動時

### 成長制限
- 成長するのは**最大値**

### 成長の意味
- 数値上昇ではなく
- **運営方針・組織の性格が定着した結果**

---

## アイテムシステム

### アイテムの入手
- イベント対応時に獲得
- 通常行動時に獲得
- 入手確率・種類は行動内容による

### アイテムの使用
- **行動フェーズ中、任意のタイミングで使用可能**
- **行動枠を消費しない**
- 1ターンに複数使用可能

### アイテムの効果例
- **コスト軽減**: N/C/Tの消費を減少
- **効果増強**: 行動の効果を上昇
- **イベント緩和**: リスクイベントの悪影響を軽減
- **臨時収入**: 即座に資金を獲得（運営フェーズ）
- **パラメータ回復**: N/C/Tを即座に回復

### アイテム管理
- 所持上限あり（検討中）
- 使い捨て消耗品
- 次月への持ち越し可能

---

## フェーズ移行

### 2年目終了 → 運営フェーズへ
- リリース演出
- 初期ユーザー数の決定
  - N / C / T の値に応じて算出

### 3年目終了 → 借金判定
- 借金残高チェック
- **残債あり**: ゲームオーバー
- **完済**: 運営2年目へ進行

### 5年目終了 → 最終評価
- セルラン順位
- 総合スコア
- エンディング演出

---

## 設計思想

- **選択の重み**: 毎月の行動選択が結果に影響
- **リソース管理**: 限られた行動枠とコストの最適配分
- **運と実力**: イベントのランダム性と対応の戦略性
- **長期的視点**: 短期の収益と長期の成長のバランス

---

## 実装上の注意点

### 現行実装からの主な変更
- パラメータを N / C / T に統一
- エネルギーシステム → リソース全回復制
- カード選択 → イベント/通常行動の選択
- クリティカルヒット → 削除または簡略化

### 維持する要素
- 2フェーズ制の構造
- 借金システム
- ユーザー数・収益管理
