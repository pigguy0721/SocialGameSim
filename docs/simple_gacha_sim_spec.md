# ガチャ編成型 経営シミュレーション仕様書

## 概要

プレイヤーは毎月ガチャでキャラを獲得し、
5枠の編成を組んで収益を発生させながら
3年間の資金生存を目指す経営シミュレーション。

リスクと収益のトレードオフ管理がゲーム性の核。

---

# 勝利条件

36ヶ月（3年）資金が0にならない

```
資金 <= 0 → 破産
```

---

# 基本パラメータ

| 項目    | 値            |
| ----- | ------------ |
| 初期資金  | 3,000,000    |
| 期間    | 36ヶ月         |
| 編成枠   | 5            |
| キャラ保持 | 最大3ヶ月        |
| ガチャ1回 | 100,000（調整可） |
| 維持費   | 自動調整         |

---

# 月の流れ

## 月初

1. ガチャを任意回数引く
2. 獲得キャラから5枠編成
3. 収益計算
4. 炎上判定
5. 維持費支払い

---

# キャラ仕様

## レアリティ

* N
* R
* SR
* SSR

レア度により効果量が変動。

---

## 効果タイプ（いずれか1つ）

| タイプ     | 効果     |
| ------- | ------ |
| ガチャ強化   | 収益倍率UP |
| 技術力UP   | 基礎収益UP |
| コンテンツUP | 安定性UP  |
| バフ      | 全体倍率UP |

---

## キャラ寿命

* 3ヶ月持ち越し可能
* 期限切れで消滅

---

# 編成

5枠に自由配置。

編成バランスが重要。

```
偏りすぎ → 炎上率UP
バランス良 → 安定
```

---

# 収益計算

```
基礎収益
× キャラ補正
× バフ倍率
× ランダムブレ
```

---

# 炎上システム

## 発生条件

* 編成バランス悪
* 評価低
* ギャンブル寄り

## 効果

```
収益大幅減
資金減少
評価低下
```

炎上は**上振れとセット**。

---

# 戦略タイプ

プレイヤーの行動で結果が変化。

## SAFE

* ガチャ少
* 安定編成
* 炎上低

## NORMAL

* 中間
* 生存率基準

## GAMBLE

* ガチャ多
* 偏重編成
* 炎上高
* 爆益あり

---

# 維持費

毎月固定支払い。

```
資金 += 収益
資金 -= 維持費
```

NORMAL戦略の生存率が
**約30%** になるよう自動調整。

---

# 生存率設計目標

| 戦略     | 生存率    |
| ------ | ------ |
| SAFE   | 60〜80% |
| NORMAL | 約30%   |
| GAMBLE | 5〜20%  |

---

# 出力指標

シミュ結果として出力：

* 生存率
* 最大資金
* 最小資金
* 平均資金
* 中央値

中央値を最重要指標とする。

---

# ガチャテーブル（固定）

例：

| レア  | 確率  |
| --- | --- |
| N   | 60% |
| R   | 25% |
| SR  | 10% |
| SSR | 5%  |

---

# ガチャ戦略性

プレイヤー判断：

* 何回引くか
* どの編成にするか
* 安定 or 爆死

```
ガチャ多 → 爆益 or 破産
```

---

# バランス思想

このゲームの面白さは：

```
安定すると稼げない
攻めると死ぬ
```

---

# 数値設計哲学

重要なのは平均ではなく：

* 中央値
* 破産率
* 上振れ幅

プレイヤー体験の大半は中央値に収束する。
