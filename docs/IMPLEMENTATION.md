## ゲームシステム

### 1. ガチャシステム

#### 概要
プレイヤーは資金を消費してキャラクターを獲得する。

#### レアリティ確率
| レアリティ | 確率 | 効果量 |
|-----------|-----|--------|
| N         | 60% | 小     |
| R         | 25% | 中     |
| SR        | 10% | 大     |
| SSR       | 5%  | 特大   |

#### 効果タイプ（4種類）
- **ガチャ強化**: 収益に乗算（1.05～1.50倍）
- **技術力UP**: 収益に加算（5,000～50,000円）
- **コンテンツUP**: 収益に乗算（1.05～1.50倍）
- **バフ**: 収益に乗算（1.02～1.20倍）

#### 実装関数
```lua
function rollGacha()
  -- 確率テーブルから抽選
  -- 効果タイプをランダム選択
  -- キャラクター生成
end

function createCharacter(rarity, effectType)
  -- レアリティと効果タイプから効果量を決定
  -- 寿命を設定（デフォルト3ヶ月）
end
```

#### キャラクター寿命
- 各キャラは**3ヶ月**で消滅
- 月末処理でlifetime-1
- lifetime=0で自動削除

### 2. 編成システム

#### 概要
獲得したキャラクターから5枠の編成を組む。

#### バランススコア計算
編成の偏りを数値化する指標。スコアが高いほど炎上リスク増。

```lua
function calculateTeamBalance(currentTeam)
  -- 4種類の効果タイプの分布を集計
  -- 標準偏差を計算
  -- 空枠ペナルティを加算（+15/枠）
  balanceScore = 標準偏差 × 30 + 空枠数 × 15
end
```

**計算例:**
- 全タイプバランス良（各1枚ずつ）: スコア低（炎上率低）
- 1タイプ偏重（ガチャ強化5枚）: スコア高（炎上率高）
- 空枠3つ: +45のペナルティ

---

### 3. 収益計算システム

#### 収益計算式
```lua
収益 = (基礎収益 + 技術ボーナス)
     × ガチャ倍率
     × コンテンツ倍率
     × バフ倍率
     × ランダムブレ
```

#### ランダムブレ
手動プレイ/オートプレイ共通で**±20%**のブレ幅

```lua

  -- 各効果タイプの累積値を計算
  -- 最終収益を計算
  -- ランダムブレを適用（0.8～1.2倍）
end
```

### 4. 炎上システム

#### 概要
編成バランスが悪いと発生する負のイベント。

#### 炎上確率計算式
```lua
炎上確率 = バランススコア × 0.5% + (10 - 評価) × 2%
最大80%（必ず炎上することはない）
```

#### 炎上ペナルティ
- **資金減少**: 現在資金の40%を失う
- **評価減少**: -2ポイント

```lua
function checkFire(balanceScore, reputation)
  -- 基本確率 = バランススコア × 0.005
  -- 評価修正 = (10 - 評価) × 0.02
  -- 合計確率 = min(0.80, 基本確率 + 評価修正)
  return 炎上判定結果, 炎上確率
end
```

### 5. 月次処理

#### 処理フロー
1. **編成バランス計算**
2. **収益計算**（資金に加算）
3. **炎上判定**（ペナルティ適用）
4. **維持費支払い**（資金から減算）
5. **キャラ寿命減少**（期限切れキャラ削除）
6. **月を進める**


## ゲームバランス設計思想

### 中央値重視
平均値ではなく**中央値**がプレイヤー体験を決定する。

### リスク/リターンのトレードオフ
- **ガチャ多め** → 強キャラ獲得 → 資金不足リスク
- **編成偏重** → 収益増加 → 炎上リスク増
- **安全プレイ** → 炎上少 → 収益不足で破産

### 収益ブレの役割
±20%のランダムブレにより、同じ編成でも毎月結果が異なる。
運要素を加えることで、リプレイ性が向上。

### 生存率の目標設計
- **手動プレイ（熟練者）**: 50-70%
- **オートプレイ（ランダムAI）**: 20-40%

AIは最適戦略を取らないため、生存率は低め。

## 拡張性とカスタマイズ

### パラメータ調整
`DEFAULT_VALUES`テーブルを編集することで、デフォルト値変更可能。

### レアリティ確率変更
```lua
local gachaTable = {
  {rarity="N", prob=0.60},
  {rarity="R", prob=0.25},
  {rarity="SR", prob=0.10},
  {rarity="SSR", prob=0.05}
}
```

### 効果量調整
```lua
local rarityEffects = {
  N = {gacha_boost=1.05, tech_up=5000, ...},
  ...
}
```

### 新しい効果タイプ追加
1. `effectTypes`配列に追加
2. `effectTypeNames`に表示名追加
3. `rarityEffects`に効果量追加
4. `calculateRevenue()`で計算ロジック追加

### オートプレイAI改良
`runAutoplay()`関数内のガチャ回数・編成ロジックを変更可能。

例: 資金に応じて適応的にガチャ回数を決定
```lua
local gachaCount = 0
if localState.money > 2000000 then
  gachaCount = 3
elseif localState.money > 1000000 then
  gachaCount = 2
else
  gachaCount = 1
end
```
